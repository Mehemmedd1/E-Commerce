🛒 E-Commerce Backend (Spring Boot)

A secure and scalable E-Commerce Backend API built with Java Spring Boot, supporting user authentication, product management, cart operations, and admin functionalities.

🚀 Features
👤 Authentication & Authorization

User registration & login

Admin login

JWT based authentication

Spring Security integration

OTP verification

🛍️ Product & Cart Management

CRUD operations for products (Admin)

Add / remove / update cart items

View cart with total calculation

📦 Tech Stack

Java 

Spring Boot

Spring Web

Spring Security

Spring Data JPA

Lombok

PostgreSQL

JWT

Maven
